# Overland Map destinations

Quick answer: the Overland Map "represents the northern hemisphere of Arrakis"; flying it costs fuel and time spent on it costs water (game text). Leave a map with a flying vehicle, at least 50% fuel and 30% hydration, no passengers and nothing harnessed (game text). Destinations below are game text (`OvermapHudPOI_*`, `Travel_MapName_*`); details are in [../world-and-maps.md](../world-and-maps.md).

| Destination | What it is (game text) | Notes |
|---|---|---|
| Hagga Basin | Home survival map | Always running here (verified on this server) |
| Arrakeen, Harko Village | Social hubs | See their entries |
| Deep Desert | Endgame map | Enter over the Shield Wall |
| Wreck of the Hephaestus, Ruins of Old Carthag, Water Shipper's Mansion | Story maps (Chapters 1 and 2) | |
| Arrakeen Spaceport, Sardaukar Orbital Bastion | Chapter 4 | |
| Neo Carthag Arena, Arsunt Garrison, Fallen Light | Chapter 3 | Arena taxi from Harko Village (wiki) |
| The Broodworks | Bandit stronghold on the Shield Wall | |
| Ruins of Tsimpo | "A box-canyon village decimated during the war"; enemies "Ghosts of Tsimpo" with an experimental Solido projection (game text NPC names) | |
| Wind Pass | Canyon village "repurposed by the secretive Water Shippers" | Water Shipper enemies (Bewt guards) are likely here; unverified |
| The Old Quarry, Polar Sink | Water Shipper quarry near the Polar Sink; Polar Sink needs a "polar-treated PSU" | Polar Sink strings are still placeholders ("PH_") in this build |
| Wreck of the Tyche | Irradiated wreck inside the Shield Wall | |
| Smuggler's Run | Ground-vehicle course on a rock island | |
| Blushing Cavern | Bandit camps on an erythrite cave; deserter bosses Leon and Cassian (game text NPC names) | |
| Station 15 | Its own component, "Station 15 Component" (game text) | |
| Abandoned former military outpost | | |
| Imperial Testing Stations No. 136, 24, 152, 195, 89 | Fire, Darkness, Electricity, Poison, Radiation | See [imperial-testing-stations](imperial-testing-stations.frontmatter.md) |

Some trips need "an active compatible Landsraad Mission" (game text). In instanced locations your ornithopter is "inaccessible until you leave" (game text). On this server every map but Hagga Basin starts on demand and the first arrival can take a little longer (verified on this server, docs/operations.md).
