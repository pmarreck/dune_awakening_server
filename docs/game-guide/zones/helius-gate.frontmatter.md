# Helius Gate

Quick answer: House Atreides' main base in Hagga Basin, in the Shield Wall (game text map key `ShieldWall_FortressAtreides`; wiki says eastern Shield Wall). An Atreides Quartermaster with the same stock as the one in Arrakeen and an Atreides Steward selling faction rewards are here, so Atreides players can buy the Atreides building set and furniture without flying to the city (wiki, https://awakening.wiki/Helius_Gate, 2026-09-26; https://awakening.wiki/Atreides_Quartermaster).

| NPC | Role | Source |
|---|---|---|
| Sister Mesa | Bene Gesserit training lead | game text |
| Andrea Ganan | Atreides Mentat and journey faction officer | wiki; name in game text |
| Atreides Quartermaster | Atreides-only shop: building set, lights, furniture, Scout Ornithopter parts, vehicle and armor variants | wiki |
| Atreides Steward | Atreides faction rewards | wiki; speaker name in game text |
| Duncan Idaho | Atreides soldier (story) | wiki; game text |
| Chayson Vernius, Asher Vandor, Theo Skordi | Landsraad contacts for Houses Vernius, Richese and Hagal (Skordi in a nearby cave) | wiki |
| Atreides Landsraad Representative | North of the gate | wiki |

The wiki calls the area "prime real estate for base building" for nearby basalt and aluminum and easy access to mid-game areas (wiki). See [../residences/base-sites-by-region.frontmatter.md](../residences/base-sites-by-region.frontmatter.md). Claims cannot overlap NPC sites (official blog 2025, via [../bases-and-building.md](../bases-and-building.md)), so build near it, not on it.
