# Deep Desert outposts

Quick answer: build small and disposable. The Deep Desert journey asks only for "a temporary base" of 4 foundations, 7 walls and a door, and 4 roof pieces (game text). Building there costs 50% less and demolishing refunds 100% (game text), and the weekly Coriolis storm "will destroy everything in the Deep Desert" (game text), so tear down and take everything home before it hits.

## Rules (game text unless tagged)

- Base Backup does not work there by default ("Base Backup is not possible in this region"), and base recycling is unavailable for Deep Desert bases (1.5 announcement, via the bases chapter). Use a Solido Replicator to keep the design (community, pre-1.5, method.gg).
- Official worlds run separate PvE and PvP instances; in PvP, bases with shields down can be raided (1.5 announcement; patch notes 1.3.20.0). In single-player the Deep Desert never resets (patch notes 1.5). Whether this server separates instances, and whether its Coriolis wipe still runs with damage off, is unverified.
- Only flying vehicles carry cargo home; ornithopter storage travels with you (game text; world chapter).

## Where (community, pre-split 2025 advice)

A 2025 guide, written before the PvE/PvP instance split of 1.3.20.0, suggested (community, pre-1.5, https://www.method.gg/dune-awakening/building-in-the-deep-desert-in-dune-awakening-a-full-guide):

- Row A near the center (about A5) for a relaxed base close to Hagga Basin, the Row A wrecks and the fixed testing stations.
- Upper Row D or lower Row E, columns 4 to 6, for the best access to all content, at the cost of a longer trip home; shift east or west toward the week's resources.
- Next to titanium or stravidium hotspots for maximum farming, which needs a group to defend in PvP.

Rows A and B keep fixed points of interest; the rest changes each reset (game text; wiki), so check the map after each storm.

## What to build

- Minimal: storage, a generator, maybe a refinery (community, pre-1.5, method.gg).
- Plastone walls rather than granite; granite needs constant repair from storms there (community, pre-1.5, method.gg). Plastone is "used in sandstorm-resistant construction" (game text).
- Bring an Assault Ornithopter with storage and boost modules for hauling, and unload into dedicated containers at home (community, pre-1.5, method.gg).
