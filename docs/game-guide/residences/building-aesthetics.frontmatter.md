# Building sets and base aesthetics

Quick answer: the starter CHOAM Shelter set is boxy and functional; research the CHOAM Facility set (the late journey asks you to, "Research CHOAM Facility building set", game text), buy a faction set from your House's quartermaster, or use a DLC set (Smuggler, Water Shipper, Sardaukar). Dress it with furniture and light sets from vendors, and recolor with swatches. Full set details are in [../bases-and-building.md](../bases-and-building.md); this entry adds where to buy and style advice.

## Where to get sets and furniture

| Set | Source |
|---|---|
| CHOAM Shelter (starter) | Available from the start (game text) |
| CHOAM Facility | Research (game text journey; community) |
| Atreides Stronghold (construction set) | Atreides Quartermaster, Arrakeen and Helius Gate: 80,000 Solari (wiki, https://awakening.wiki/Atreides_Quartermaster) |
| Harkonnen set | Harkonnen Acquisitor (Harko Village, Riftwatch); price unverified, a 2025 guide said the same 80,000 as Atreides (community, pre-1.5, method.gg) |
| Atreides Basic Lights, Office, Bedroom, Dining Room furniture | Atreides Quartermaster: 5,000 / 10,000 / 15,000 / 15,000 Solari (wiki) |
| CHOAM Advanced Lights, Dining Room, Bedroom, Office furniture | Zoe at The Crossroads (wiki, https://awakening.wiki/Zoe); CHOAM Office Furniture Patent from Myr Charki at Griffin's Reach (wiki); a CHOAM furniture set at The Anvil (game text journey, inference) |
| Smuggler, Water Shipper, Sardaukar sets | DLC (Raiders of the Broken Lands, The Water Wars, Filmic Archive) (see bases chapter) |
| Observer hatch and door, Desert Mechanic decorations | Decor and structure vendors (patch notes 1.3.0.0; community) |
| Swatches | Faction quartermasters (500 Solari each, wiki); faction swatches at faction rank 10 (patch notes 1.3.0.0); Landsraad Cosmetic Vendor in Harko Village (wiki) |

The faction Stronghold sets build in Plastone (community, pre-1.5, method.gg Deep Desert guide), "an artificial composite of Silicone and Basalt used in sandstorm-resistant construction" (game text). So a faction base also wants basalt (Shield Wall, Mysa Tarill) and silicone (flour sand, Vermillius Gap).

## Style advice players give

From a 2025 guide (community, pre-1.5, https://www.keengamer.com/articles/guides/how-to-build-the-perfect-base-dune-awakening/):

- Avoid "Borg cube" boxes: use triangle floors, wedges and angled walls. The CHOAM Shelter set has Triangle and Rounded foundations and floors, Rounded Windows, ramps and railings for this (game text piece names).
- Build into cliffsides and rocks for natural support and a less exposed silhouette.
- Break up flat walls with windows or indents, support overhangs with pillars or ramps, and vary the roofline with towers.
- Placeables and containers can be renamed since 1.5 (1.5 announcement, via the bases chapter), which helps label storage rooms.

The Sardaukar set gained mirrored versions of asymmetric pieces and a missing Corner Column in 1.5 (patch notes 1.5).
