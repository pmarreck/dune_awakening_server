# Cutteray in combat

Quick answer: treat the Cutteray as a tool, not a weapon. Game text describes it only as mining ore and salvage and cutting open certain doors, and no source found says it damages players or NPCs (game text; community search, https://www.method.gg/dune-awakening/dune-awakening-best-tools-tier-list). Whether its beam hurts a creature is unverified; test it on this server before relying on it.

Where it still matters in a fight:

- Testing Stations have locked doors and hidden loot rooms you open with a Cutteray (wiki, https://awakening.wiki/Testing_Station_89 and https://awakening.wiki/Testing_Station_136).
- The lasgun quest "Cutting Edge" starts by handing in a new Cutteray Mk6 (community, https://www.method.gg/dune-awakening/how-to-get-a-lasgun-in-dune-awakening-cutting-edge-quest-reward, pre-1.5). See [lasguns](lasguns.frontmatter.md).
- Vehicle-mounted Cutterays exist on buggies; whether they damage targets is also unverified.
