# Stillsuits as armor

Quick answer: stillsuits are worn in the armor slots and carry an Armor Value, so they double as light protection while saving water; since 1.5 a stillsuit top covers both chest and leg slots (game text; patch notes 1.5, https://duneawakening.com/news/dune-awakening-console-release-patch-notes/). Water details and the tier list are in [../survival-combat-crafting.md](../survival-combat-crafting.md#stillsuits).

## Combat-relevant stillsuits (game text)

| Name | Note |
|---|---|
| Hollower, Menol's, Kel's, Shadrath's, Saturnine, Imperial (armored uniques, tiers 1 to 6 by id) | "Armored" stillsuits; Menol's leathers are "stiffer, more protective"; the CHOAM-made Imperial suit is "highly armored, which makes it useful in combat". |
| Crew Chief's (dashed) stillsuits, tiers 2 to 6 | Lightweight tops that reduce dash stamina cost. One drops in Testing Station 89 (wiki, https://awakening.wiki/Testing_Station_89). |
| Planetologist school set | Unpacks into "Unique stillsuits" (game text). |
| Maas Kharet Stillsuit Set | Unique stillsuit from a container. |

Whether a full stillsuit beats light combat armor on blade or dart mitigation at the same tier is unverified; compare the item cards in game. The armored Imperial stillsuit pieces drop at 6.0% each in Testing Station 195 (wiki, https://awakening.wiki/Testing_Station_195).
