# Scatterguns (GRDA 44)

Quick answer: the GRDA 44 is the "wide range" pellet scattergun, many darts per pull for close-in brutality; the Vermillius Gap journey sums it up as "The Scattergun brings close-in brutality" (game text). Scattergun Damage (Trooper passive) covers both the GRDA 44 and the Drillshot FK7 (game text).

## Craftable line (names game text, ids item data)

Standard GRDA 44 (`Scattergun_Prototype`), Artisan (`Scattergun_Prototype0`), House (`Scattergun_Prototype1`), Adept (`Scattergun_Prototype2`), Regis (`Scattergun_Prototype3`).

## Uniques (effects game text)

| Family | Names | Effect |
|---|---|---|
| Shrapnel | Shredder, Ripper, Eviscerator, Syndicate Impaler, Perforator | Darts break into shrapnel and cause bleeding. |
| Molten mass | Firestorm (Al), Starburst (Dural), Shellburster (Plast) | Laser-heated darts burst into flaming particles. |

## Augments (game text)

GRDA 44 Tactical Amplifier, Expander, Amplifier, Optimizer, Sprayer, Micro-Rigidity Coating; Scattergun Rampage-Enhancement (damage and magazine for less critical damage), which 1.5 extended to the Drillshot FK7 as well (patch notes 1.5, https://duneawakening.com/news/dune-awakening-console-release-patch-notes/). An older "GRDA 44 Poison Coater" mod exists in text (obtainability unverified).

A scattergun burst is the suggested opener against Lieutenant Aman in Testing Station 89 (wiki, https://awakening.wiki/Testing_Station_89).
