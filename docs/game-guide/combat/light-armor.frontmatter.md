# Light armor (scout armor)

Quick answer: light ("scout") armor offers less protection than heavy armor "in exchange for better water discipline and ease of movement" (game text, Jabal Eifrit journey). In practice it lowers dash stamina cost and leans on blade mitigation; heavy armor has more armor and dart mitigation (community, https://www.method.gg/dune-awakening/dune-awakening-best-armor-tier-list). There is no medium category in 1.5 game text, though old "Armor Kit: Medium" items exist (game text).

## Sets by tier (names game text; tier from the id suffix where it has one)

| Tier | Light set |
|---|---|
| 1 copper | The first journey crafts "a makeshift outfit from plant fiber" (game text); Woven Fiber, Scavenger and Makeshift pieces are likely starters (tier unverified) |
| 2 iron | Kirab Light (`KIRABLIGHT_T2`), Kirab Scout |
| 3 steel | Slaver Light (`SLAVERLIGHT_T3`), Slaver Scout (crafted in the Jabal Eifrit journey) |
| 4 aluminum | Sandflies Light (`SANDFLIESLIGHT_T4`), Duneman Scout |
| 5 duraluminum | Mercenary Light (`MERCLIGHT_T5`), Mercenary Scout |
| 6 plastanium | CHOAM Scout |

Faction sets (Atreides Scout, Harkonnen Scout) and DLC/store sets also exist (game text).

## Notable light uniques (effects game text)

| Name | Effect |
|---|---|
| Phantom Whisper Chestpiece | 5% detection speed reduction (stealth). |
| Red Scorpion's set | Unique armor from an armor container ("Red Scorpion Armor Set", listed under heavy T5 in its id). |
| Skin-lined Jacket, Miner's Blessing, Station Garb, Desert Garb | Light tops with biome heat protection (id `BIOMEHEAT`); Desert Garb drops in Testing Station 24 (wiki, https://awakening.wiki/Testing_Station_24). |
| Compression-Stim Leggings, Stim-Leggings | Lower dash stamina drain. |
| School sets (Bene Gesserit, Mentat, Planetologist, Swordmaster) | See [school armor sets](school-armor-sets.frontmatter.md). |

Garment augments (plastanium uniques only) tune resistances; see [augments](augments.frontmatter.md).
