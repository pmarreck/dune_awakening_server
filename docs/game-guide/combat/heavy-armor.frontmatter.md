# Heavy armor

Quick answer: "Heavy Armor turns aside the blades and darts of my enemies" but is "still not without drawbacks" (game text, journeys): higher armor and dart mitigation, more expensive dashes and worse water discipline than light armor (game text; community, https://www.method.gg/dune-awakening/dune-awakening-best-armor-tier-list).

## Sets by tier (names game text; tier from id suffix or journey)

| Tier | Heavy set |
|---|---|
| 2 iron | Kirab Heavy (`KIRABHEAVY_T2`; crafted in the Vermillius Gap journey as "Kirab Heavy Armor") |
| 3 steel | Slaver Heavy (`SLAVERHEAVY_T3`) |
| 4 aluminum | Sandflies Heavy (`SANDFLIESHEAVY_T4`); Duneman Heavy Armor (crafted in the O'odham journey) |
| 5 duraluminum | Mercenary Heavy (`MERCHEAVY_T5`) |
| 6 plastanium | CHOAM Heavy |

Faction heavy sets (Atreides Heavy, Harkonnen Heavy, deserter variants) and DLC sets (Harkonnen Cataphract, Atreides Hoplite, Sardaukar sets; Filmic Archive DLC, patch notes 1.5) exist too.

## Notable heavy uniques (effects game text)

| Name | Effect |
|---|---|
| Combat Exoskeleton Chestpiece | +10% melee damage. |
| Fortress Chestpiece | Materials "become exceptionally dense when stationary" (damage reduction while standing still, id `STANDSTILLDMGREDUCTION`). |
| Power Harness | Extra power reserves for mining and suspensors. Drops in Testing Station 152 (wiki, https://awakening.wiki/Testing_Station_152). |
| Bulwark Chest, Mendek's Chestplate | "Reinforced" heavy uniques (id `REINFORCED`); exact bonus unverified. |
| Syndicate Chestplate (The Forge set) | Keeps environmental hazards at bay; the wiki recommends the Forge set for early levels (1 to 15) of the electrical, poison and fire Testing Stations (wiki, same page). |
| Trooper Heavy Armor Tactical Coat | Trooper school set; see [school armor sets](school-armor-sets.frontmatter.md). |
| Tunic of Ginaz | Swordmaster set; its chest id says heavy, but its container calls it light (game text). |
