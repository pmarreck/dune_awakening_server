# Light machine guns (Vulcan GAU-92)

Quick answer: the Vulcan GAU-92 is a heavy weapon with a large magazine and high fire rate, "used for crowd control against multiple opponents" (game text). Constant fire slows a shielded target (wiki, https://awakening.wiki/Holtzman_Shield). Heavy weapons slow you down; Trooper's Heavy Weapon Agility lets you move faster with them and Heavy Weapon Damage adds damage (game text).

## Lines (names game text, ids item data)

Atreides LMG (`AtreLMG1`), House Vulcan GAU-92 (`AtreLMG3`), Adept (`AtreLMG4`), Regis (`AtreLMG5`). It arrives with the aluminum-tier O'odham journey: "brute strength, but effective" (game text).

## Uniques (effects game text)

| Name | Effect |
|---|---|
| Experimental Vulcan GAU-94, Extravagant Message, Bashar's Command | Expanded dart capacity. |
| Plasma Cannon (`LMG_Unique_Power_06`) | Fires superheated darts (its item text is a DOOM joke). |
| The Hateful Barker (Chapter 4) | Very inaccurate, +25% damage. |

## Augments (game text)

VULCAN GAU-92 Expander, Focuser, Disruptive Coating, Sprayer, Accelerator. An older "LMG Explosive Gel" mod exists in text (obtainability unverified).
