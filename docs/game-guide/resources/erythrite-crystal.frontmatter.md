# Erythrite Crystal

Erythrite is "mined from an Erythrite deposit in the Hagga Rift" (game text) and refined into Cobalt Paste, which almost every tool, vehicle module and power pack from steel tier up needs. A Cutteray Mk2 is enough (it is a tier 3 mineral with carbon; game text, mining info card).

| Fact | Value | Source |
|---|---|---|
| Item id | `ErythriteCrystal`, stacks to 500 | item data |
| Tool | Cutteray Mk2 or better; Callie's Breaker gives extra carbon and erythrite | game text |
| Where | Mostly inside the CHOAM Mineral Extraction Facilities in the Hagga Rift; also near facility entrances, in Rift caves and scattered across the Rift | wiki, https://awakening.wiki/Erythrite_Crystal (edited 2026-10-05) |
| Also | The long tunnel that starts near Riftwatch; caves marked with the erythrite map icon; loose crystals around pink-crusted rock piles; crates in the facilities | community, https://www.thegamer.com/dune-awakening-erythite-crystals-location-guide/ (pre-1.5) |
| Overland | Blushing Cavern, "a small rock island with bandit camps atop a large cave of erythrite" | game text |
| Vendor | not listed | |

Game text lore: the Rift's "abandoned mining galleries" are where the crystals are "most commonly found", and the Rift was fought over for them (game text). The Hagga Rift has seven CHOAM Mineral Extraction Facilities (game text, see [zones/hagga-rift](../zones/hagga-rift.frontmatter.md)); they are guarded, so newer players often start with the caves (community, thegamer).

## Refining (Cobalt Paste)

| Refinery | Input | Output | Time |
|---|---|---|---|
| Small Chemical Refinery | 3 Erythrite + 75 mL water | 1 Cobalt Paste | 15 s |
| Medium Chemical Refinery | 2 Erythrite + 75 mL water | 1 Cobalt Paste | 10 s |

(wiki, https://awakening.wiki/Erythrite_Crystal.) Yield by cutteray for the carbon/erythrite group (wiki, unit not stated): Mk2 45, Mk3 60, Mk4 90, Mk5 130, Mk6 170.

Rarity: localized to the Rift, but the facilities restock, so you can farm them repeatedly (community, thegamer, pre-1.5).
