# Plant Fiber

Plant Fiber "can be picked everywhere in the world where there is solid land for it to take root" and is "woven to fibers used in armor and bandages" (game text). Gather it by hand with the interact key; no tool is needed (wiki, https://awakening.wiki/Plant_Fiber, edited 2026-10-03).

| Fact | Value | Source |
|---|---|---|
| Item id | `PlantFiber`, stacks to 500 | item data |
| Where | Any solid ground; the map's Foliage filter shows plants | game text |
| Uses | Healkits (early ones are crafted from Plant Fiber); Small Blood Sack (25 fiber + 5 Salvaged Metal); armor | game text; wiki, https://awakening.wiki/Salvaged_Metal |
| 1.5.3.1 fix | Some plants "failed to yield resources and left the plant in the world"; fixed in hotfix 1.5.3.1 (2026-09-19) | patch notes, https://duneawakening.com/news/dune-awakening-console-release-patch-notes/ |

Yield per plant is not documented (unverified). The skill stat "Pickup Yield" exists (game text) and presumably raises hand-gathered amounts (inference).
