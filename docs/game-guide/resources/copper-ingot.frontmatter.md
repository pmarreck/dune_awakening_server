# Copper Ingot

"A Copper ingot, refined from Copper Ore at any Ore Refinery" (game text). Item id `CopperBar`, stacks to 500 (item data).

| Refinery | Input | Time |
|---|---|---|
| Small Ore Refinery | 4 Copper Ore | 5 s |
| Medium Ore Refinery | 3 Copper Ore | 4 s |
| Large Ore Refinery | 2 Copper Ore | 3 s |

No water (wiki, https://awakening.wiki/Copper_Ore, edited 2026-10-05).

Examples of use (wiki per-item pages, edited 2026-10-05): Cutteray Mk1 (6 Copper Ingot + 4 EMF Generator), Power Pack Mk1 (5 Copper Ingot + 3 Particle Capacitor), Literjon (14 Copper Ingot + 2 Micro-Sandwich Fabric). Copper is material tier 1 for armor, weapons and stillsuits (game text).
