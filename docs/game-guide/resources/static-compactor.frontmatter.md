# Static Compactor

"Point and shoot at flour sand or spice sand to compact it into a clump that can be picked up ... Depletes power from a Power Pack on use" (game text). It also uncovers buried treasure that a Scanner finds after a storm and clears fire and poison clouds (game text). Hand harvesting works but is slow; the game itself says "use a compactor" (game text).

Ids from item data; wiki pages edited 2026-10-05. The Compact Compactor "draws less power and reduces worm attention" (game text), the one compactor built for staying on the sand longer. The Industrial was "once called the Particle Agglomerator" (game text flavor). The Omni's game text mentions only spice fields; whether it still takes flour sand is unverified.

One guide says the basic Static Compactor unlocks after the second Trial of Aql (community, https://www.method.gg/dune-awakening/flour-sand-farming-spot-dune-awakening-dont-die-to-the-worm-with-these-handy-tips, pre-1.5, unverified). The stat "Compactor Yield" raises its output (game text).
