# Blood Extractor

"Equip and use this to extract blood from dead bodies into a Blood Sack. Blood can be processed into water with a Blood Purifier in your base" (game text). Drinking the sack directly rehydrates, "but max health will suffer" (game text). Blood sacks and their capacities are in [survival-combat-crafting.md](../survival-combat-crafting.md).

| Tool (id) | Notes | Source |
|---|---|---|
| Improvised Blood Extractor (`BodyFluidExtractor`) | "A crude device"; 20 Salvaged Metal | game text; wiki, https://awakening.wiki/Salvaged_Metal |
| Blood Extractor Mk2 (`BodyFluidExtractor_02`) | | game text; item data |
| Blood Extractor Mk4 (`BodyFluidExtractor_03`) | Uses Cobalt Paste | wiki, https://awakening.wiki/Cobalt_Paste |
| Blood Extractor Mk6 (`BodyFluidExtractor_2h_tier6`) | Two-handed | item data |
| Filter Extractor Mk3 to Mk6 (unique, `BodyFluidExtractor_Unique_Water_03..06`) | Filters some blood straight to pure water | game text |
| Impure Extractor Mk5 and Mk6 (unique, `BodyFluidExtractor_Unique_Poison_05/06`) | Extracts more fluid; excess becomes poison on your weapons | game text |

Community yield figures run from about 1,000 mL per body (Improvised) to about 6,000 mL (Mk6) (community, cited in [survival-combat-crafting.md](../survival-combat-crafting.md), unverified). The stat "Blood Extraction Yield" raises it (game text). Whole corpses (`Corpse`) can instead go into a Deathstill (game text).
