# Agave Seeds

Agave Seeds are "harvested from cactus crowns" of the Arrakeen Agave (game text). They are found "at set spawn locations in The O'odham" (wiki, https://awakening.wiki/Agave_Seeds, edited 2026-10-05), and a resource scanner helps find them. Their main use is the Iodine Pill, which protects against radiation in the Sheol and other irradiated places.

| Fact | Value | Source |
|---|---|---|
| Item id | `SaguaroResourceRaw`, stacks to 500 | item data |
| Gathering | By hand from the cactus top; plants show a long thin stem with a bright red flower; easier to spot by day | community, https://method.gg/dune-awakening/where-to-find-agave-seeds-for-iodine-pills-in-dune-awakening (pre-1.5) |
| Where | The O'odham (northwest Hagga Basin), denser near the "Giant Cactus"; a few elsewhere in Hagga Basin | wiki; community, same (pre-1.5) |
| Yield | Reports disagree: about 5 seeds per plant with a 30 to 45 minute respawn, or "a few" | community, unverified |
| Iodine Pill | Survival Fabricator: 10 Agave Seeds + 1 Duraluminum Ingot + 170 mL water makes 5 Iodine Pills in 3 s | wiki, same page |
| Trade | A dialogue option trades 100 Welding Wire for 1 Agave Seed; another sells Iodine Pills at 100 Solari each | game text |

Because the pill needs a Duraluminum Ingot, players reach it at about the same time as jasmium mining in the Sheol (inference).
