# Flour Sand

Flour Sand is "found in flour sand drifts on the open sands, predominantly in the Vermillius Gap" and refined into Silicone Blocks (game text). Look for "a cloud of white dust" over open sand; hand harvesting works, but "to harvest it efficiently, use a Static Compactor" (game text tutorial).

| Fact | Value | Source |
|---|---|---|
| Item id | `FlourSand`, stacks to 1,000 | item data |
| Tool | Hands ("Take Flour Sand") or a Static Compactor | game text |
| Where | Open sand, mostly Vermillius Gap; the wiki also shows a patch in Mysa Tarill | game text; wiki, https://awakening.wiki/Flour_Sand (edited 2026-10-05) |
| Finding it | Map filter and marker "Flour Sand"; a journey task asks you to "Locate a Flour Sand Field using a Scanner" | game text |
| Vendor base price | 10 Solari | wiki |

It sits on open sand, so harvesting builds worm threat. The game's own notes: "hand-harvesting is too slow, use a compactor ... and beware the worm" (game text, journey card). Guides suggest drifts close to rock, such as in the Eastern Vermillius Gap north of the starting zone (community, https://www.method.gg/dune-awakening/flour-sand-farming-spot-dune-awakening-dont-die-to-the-worm-with-these-handy-tips, pre-1.5). The Sandcrawler collects only spice sand, not flour sand (wiki, cited in [vehicles.md](../vehicles.md)).

Refining: Small Chemical Refinery, 5 Flour Sand + 50 mL water makes 1 Silicone Block in 15 s; Medium, 3 sand, 10 s (wiki). See [silicone-block](silicone-block.frontmatter.md).
