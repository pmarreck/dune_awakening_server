# Basalt Stone

Basalt Stone is the "base material for plastone" (game text), the advanced building material. It is a tier 4 mineral, so it needs a Cutteray Mk3 like aluminum ("Basalt and Aluminum", game text mining info card).

| Fact | Value | Source |
|---|---|---|
| Item id | `Basalt`, stacks to 500 | item data |
| Tool | Cutteray Mk3 or better | game text |
| Where | Mysa Tarill, west of Jabal Eifrit (no enemies at the spot one guide names); the Eastern Shield Wall; rocks around the Crossroads tradepost | community, https://www.sportskeeda.com/mmo/dune-awakening-how-get-farm-basalt-stone and https://deltiasgaming.com/?p=260459 (pre-1.5); [world-and-maps.md](../world-and-maps.md) lists basalt for Mysa Tarill |
| Map marker | "Basalt Stone" | game text |

Uses: Plastone, made at any Ore Refinery from Basalt Stone, one Silicone Block and 50 mL water (recipes in [plastone](plastone.frontmatter.md)). The late-game journey card for upgrading to the CHOAM Facility building set is titled "Raise the Roof" and its keys call it the basalt base (game text).

Basalt yield by cutteray (wiki, unit not stated; same group as aluminum): Mk3 36, Mk4 48, Mk5 72, Mk6 104.
