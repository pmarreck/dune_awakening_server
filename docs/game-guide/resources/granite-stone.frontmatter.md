# Granite Stone

Granite is "widely used a basic building material" and "found almost everywhere there is dirt" (game text). Any cutteray mines it, starting with the Improvised Cutteray ("works on granite, copper, metal, and doors", game text), and small rocks lie loose on the ground ("Rocks and ore pieces can be found spread across the ground", game text).

| Fact | Value | Source |
|---|---|---|
| Item id | `Stone` (display name Granite Stone), stacks to 500 | item data |
| Mining tier | Tier 1 with copper and salvage | game text, mining info card |
| Uses | Early building pieces; most Water Shipper building set pieces cost granite | game text; wiki, cited in [bases-and-building.md](../bases-and-building.md) |
| Yield | Same group as copper: Improvised 40, Mk1 48, Mk2 72 ... Mk6 200 (unit not stated); Sim's Cutter is tuned for granite, copper and salvage | wiki, https://awakening.wiki/Cutteray; game text |

Rarity: abundant. Mine it near your base rather than hauling it.
