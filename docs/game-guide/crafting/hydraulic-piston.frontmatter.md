# Hydraulic Piston

Quick answer: "A component used to craft vehicle engines", held by the Great Houses (game text). Id `T5FactionBaseComponent2` (item data). Ingredient in 7 recipes (wiki, https://awakening.wiki/Hydraulic_Piston).

- Uses (wiki recipe data, pre-1.5): Mk5 engines (Buggy Engine Mk5 7, Bluddshot Buggy Engine Mk5 13, ornithopter engines), and 3 per Tri-Forged Hydraulic Piston (+ 2 Plasteel Plate + 1 Duraluminum Ingot) for Mk6 engines (Buggy Engine Mk6 needs 9 Tri-Forged).
- Base vendor price 350 (wiki item data).
