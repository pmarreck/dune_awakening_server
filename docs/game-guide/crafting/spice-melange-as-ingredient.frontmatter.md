# Spice Melange as a crafting ingredient

Quick answer: melange is the main extra cost of plastanium gear. Ordinary Mk6 items take about 20 to 55 melange each, Mk6 uniques 50 to 190, and the large refineries hundreds to 1,000 to build. It appears in 193 recipes (wiki, https://awakening.wiki/Spice_Melange, pre-1.5 data). Item id `MelangeSpice`, stack 500 (item data).

| Example | Melange |
|---|---|
| Regis Sword / Regis Disruptor M11 | 20 / 25 |
| CHOAM Heavy Chestplate / CHOAM Stillsuit Body | 36 / 54 |
| Buggy Chassis Mk6 / Buggy Engine Mk6 | 55 / 54 |
| Bluddshot Buggy Engine Mk6 (unique) | 186 |
| Plasteel Composite Gun / Blade Parts / Armor Plating (each) | 1 |
| Advanced fabricators, Medium Chemical Refinery, Augmentation Station | 45, 35, 15 before 1.5; removed in 1.5 |
| Medium Spice Refinery / Large Ore Refinery / Large Spice Refinery | 135 / 400 / 1,000 |

Sources: wiki recipe data; patch notes 1.5 (https://duneawakening.com/news/dune-awakening-console-release-patch-notes/). Making it: 100 Spice Sand + 750 mL per melange in the small Spice Refinery, down to 50 sand + 375 mL in the Large ([refining-chains](refining-chains.frontmatter.md)). Melange is also spent on Specialization traits and respecs (progression chapter). Base vendor price 6,500 (wiki item data); it is dropped on death (wiki).
