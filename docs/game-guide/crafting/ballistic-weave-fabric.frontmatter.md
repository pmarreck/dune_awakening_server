# Ballistic Weave Fabric

Quick answer: "A light armor crafting component used in plastanium tier crafting. Can be found in the Deep Desert, obtained from Landsraad rewards or crafted in an Advanced Survival Fabricator" (game text). Recipe: 3 Sandtrout Leathers + 2 Plasteel Plate + 2 Silicone Block + 50 mL, 3 s (wiki, https://awakening.wiki/Ballistic_Weave_Fabric, pre-1.5 numbers). Id `T6BalisticWeave` (item data).

- Ingredient in 20 recipes (wiki): the CHOAM Scout set (helmet, chestplate, pants, gloves, boots), plastanium light uniques (Adrenal Boots and others), and the Radiation Suit Mk6 (9).
- Sandtrout Leathers come from the Maas Kharet ([regional-loot-components](regional-loot-components.frontmatter.md)).
- Base vendor price 440 (wiki item data).
