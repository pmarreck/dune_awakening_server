# Holtzman Actuator

Quick answer: "Those who make regular use of suspensor belts and similar technology often leave caches of these replacement parts in places only they can reach" (game text), so look in high, hard-to-reach caches. Id `T1ExplorationComponent` (item data). Ingredient in 33 recipes (wiki, https://awakening.wiki/Holtzman_Actuator).

- Uses (wiki recipe data, pre-1.5): every vehicle booster (Buggy Booster Mk3 25, Mk4 31; Sandbike Booster Mk3 25, Mk4 31), suspensor belts, Holtzman Shield Mk3 and Mk5, compactors.
- Mk6 recipes use the Improved Holtzman Actuator: 3 Holtzman Actuator + 2 Plasteel Plate + 1 Cobalt Paste (wiki).
