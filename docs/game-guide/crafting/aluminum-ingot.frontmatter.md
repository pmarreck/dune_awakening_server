# Aluminum Ingot

Quick answer: Aluminum Ore (`BauxiteOre`, Cutteray Mk3) + 200 mL water: 7 ore in the Medium Ore Refinery (30 s) or 4 in the Large (20 s). The Small Ore Refinery cannot make it (wiki, https://awakening.wiki/Aluminum_Ingot; game text). Item id `AluminiumBar` (British spelling in the id; item data).

- Every Duraluminum Ingot consumes one Aluminum Ingot (wiki).
- Used in 131 recipes, the Mk4 tier (wiki). A Mk4 buggy needs 271 (see [worked-example-buggy-mk4](worked-example-buggy-mk4.frontmatter.md)) (wiki recipe data, pre-1.5; see [index](index.frontmatter.md)).
- 1.5 cut some aluminum-tier costs by 10 to 25% (patch notes 1.5, https://duneawakening.com/news/dune-awakening-console-release-patch-notes/).
- Base vendor price 250 (wiki item data).
