# EMF Generator

Quick answer: "A fabrication component found in Fremen areas, such as caves. Used in Cutterays" (game text). It cannot be fabricated. Id `FremenComponent1` (item data). Ingredient in 50 recipes (wiki, https://awakening.wiki/EMF_Generator).

- Typical use (wiki recipe data, pre-1.5): Cutteray Mk1 4, Mk2 7, Mk3 10, Mk4 14, Mk5 18, Mk6 30; Blood Extractor Mk2 7; Mk6 dew and blood tools 24 to 28; Kynes's Cutteray 35.
- Game text also has regional variants of this family (names such as Enhanced, Efficient, Optimized, Charged, Advanced), each tied to a region from the Vermilius Gap to the Deep Desert, but their item ids carry the `D_` prefix used for deprecated items and no current recipe uses them (item data; wiki recipe data). In 1.5 one item serves every tier; see [component-families](component-families.frontmatter.md).
