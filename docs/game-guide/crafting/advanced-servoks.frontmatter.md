# Advanced Servoks

Quick answer: "A fabrication component used in vehicles such as Sandbikes. Found in Old Imperial remnants, such as Imperial Testing Stations" (game text). It cannot be fabricated. Id `OldImperialComponent1`, stack 500 (item data). Ingredient in 110 recipes (wiki, https://awakening.wiki/Advanced_Servoks).

- Typical use (wiki recipe data, pre-1.5): Sandbike Chassis Mk1 5, Mk2 8, Mk3 12, Mk4 16, Mk5 20, Mk6 27; Buggy Chassis Mk4 16, Mk6 30; Scout Ornithopter Chassis Mk5 30; each Buggy Tread Mk4 6. A Mk4 buggy needs 72 in total ([worked-example-buggy-mk4](worked-example-buggy-mk4.frontmatter.md)).
- Also in Welding Torch Mk3 (8) and Mk5 (14), vehicle storage modules, and some recipe sources list it for the Vehicle Backup Tool (vehicles chapter, conflicting).
- An item named "Advanced Servok" with `XX_NOTUSED` describes a fabricator core; it is unused (game text).
- Game text also has regional variants of this family (names such as Enhanced, Efficient, Optimized, Charged, Advanced), each tied to a region from the Vermilius Gap to the Deep Desert, but their item ids carry the `D_` prefix used for deprecated items and no current recipe uses them (item data; wiki recipe data). In 1.5 one item serves every tier; see [component-families](component-families.frontmatter.md).
