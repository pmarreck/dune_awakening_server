# Advanced Machinery

Quick answer: "An Infrastructure crafting component used in plastanium tier crafting. Can be found in the Deep Desert, obtained from Landsraad rewards, or crafted in an Advanced Survival Fabricator" (game text). Recipe: 3 Complex Machinery + 2 Plasteel Plate + 1 Cobalt Paste + 50 mL, 3 s (wiki, https://awakening.wiki/Advanced_Machinery, edited 2026-10-05, pre-1.5 numbers). Id `T6Machinery` (item data).

- Recipes using it (wiki): Bluddshot Buggy Engine Mk6, Mohandis Sandbike Engine Mk6, Walker Sandcrawler Engine Mk6 (30 each) and Sandcrawler Vacuum Mk6 (9).
- Station build costs (wiki, pre-1.5): Augmentation Station 10, Large Ore Refinery 40, Large Spice Refinery 55.
- Base vendor price 65 (wiki item data).
