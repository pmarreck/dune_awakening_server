# Mechanical Parts

Quick answer: "A fabrication component used in firearms. Found in Great House ruins, such as Shipwrecks" (game text). It cannot be fabricated. Id `GreatHouseComponent2` (item data). Ingredient in 100 recipes (wiki, https://awakening.wiki/Mechanical_Parts).

- Typical use (wiki recipe data, pre-1.5): Maula Pistol 2, Karpov 38 2, Standard Disruptor M11 5, Artisan 8, House 11, Adept 14, Regis 18; Regis Karpov 38 14.
- A second, CHOAM-flavored "Mechanical Parts" item (`RESOURCE_MECHANICAL_PARTS`, "Small mechanical components used to construct machines") also exists in game text; recipes use the Great House one (wiki).
- Game text also has regional variants of this family (names such as Enhanced, Efficient, Optimized, Charged, Advanced), each tied to a region from the Vermilius Gap to the Deep Desert, but their item ids carry the `D_` prefix used for deprecated items and no current recipe uses them (item data; wiki recipe data). In 1.5 one item serves every tier; see [component-families](component-families.frontmatter.md).
