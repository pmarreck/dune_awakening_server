# Cobalt Paste

Quick answer: Erythrite Crystal + 75 mL water in a chemical refinery: 3 crystals in the Small (15 s), 2 in the Medium (10 s) (wiki, https://awakening.wiki/Cobalt_Paste). Item id `CobaltBar`; the station description still calls it "Cobalt Ingots" (item data; game text). Erythrite needs a Cutteray Mk2 (survival chapter).

- Ingredient in 210 recipes (wiki): every Mk3+ vehicle module (a Mk4 buggy needs 110), Mk3+ Cutterays and Power Packs, the Medium Ore Refinery (60), Advanced fabricators (150 each), Large Ore Refinery (745), and several Mk6 conversions (wiki recipe data, pre-1.5; see [index](index.frontmatter.md)).
- Base vendor price 20 (wiki item data).
