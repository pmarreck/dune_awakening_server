# Armor Plating

Quick answer: "Strengthened plating can be liberated from those who make use of them in their heavy armor" (game text): loot it from Heavy enemies. Id `T2HeavyComponent` (item data). Ingredient in 81 recipes (wiki, https://awakening.wiki/Armor_Plating).

- Uses (wiki recipe data, pre-1.5): heavy armor (Kirab Heavy Jerkin 5, Slaver 9, Duneman 14, Mercenary 23), vehicle hulls and rears (Buggy Hull Mk4 21), and 115 for the Advanced Garment Fabricator.
- Game text names Thick, Fortified, Reinforced and Advanced Armor Plating, each "Found on Heavy enemies" in a later region, but recipes use only the base item (see [component-families](component-families.frontmatter.md)).
- Mk6: Plasteel Composite Armor Plating = 3 Armor Plating + 2 Plasteel Plate + 1 Spice Melange (wiki).
