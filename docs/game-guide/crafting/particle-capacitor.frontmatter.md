# Particle Capacitor

Quick answer: an Old Imperial component "found in ... Imperial Testing Stations. Used in Holtzman tech or special constructions, such as Boost modules for vehicles" (game text). It cannot be fabricated. Id `OldImperialComponent2` (item data). Ingredient in 120 recipes (wiki, https://awakening.wiki/Particle_Capacitor).

- Typical use (wiki recipe data, pre-1.5): Power Pack Mk1 3, Mk2 5, Mk3 8, Mk4 11, Mk5 11, Mk6 18; Buggy Engine Mk4 11 and PSU Mk4 20; Buggy Booster Mk4 40; Bluddshot Buggy Engine Mk6 31; Adaptive Holtzman Shield 83.
- Vehicle boosters are the big consumers: 29 to 40 per booster from Mk3 to Mk4 (wiki).
- Game text also has regional variants of this family (names such as Enhanced, Efficient, Optimized, Charged, Advanced), each tied to a region from the Vermilius Gap to the Deep Desert, but their item ids carry the `D_` prefix used for deprecated items and no current recipe uses them (item data; wiki recipe data). In 1.5 one item serves every tier; see [component-families](component-families.frontmatter.md).
