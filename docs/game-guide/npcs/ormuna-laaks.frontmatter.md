Ormuna Laaks is in Harko Village: go down the stairs, pass the contract board, and she is the second trader on the left (wiki, https://awakening.wiki/Ormuna_Laaks, edited 2026-10-06).

Stock (wiki; no prices or requirements listed): Atreides Building Set, Kirab Heavy Armor Set Variant, Harkonnen Traitor Heavy Armor Set Variant, Complex Machinery, Calibrated Servok (`T3MiningGalleryComponent1`; item data). This fits the wiki's note that opposing-faction cosmetics can be bought from settlement NPCs at double price (wiki, https://awakening.wiki/Faction; see `progression-and-skills.md`); whether Ormuna charges a faction markup is unverified.
