# Keybinds and UI features players miss

**Quick answer.** Default PC keys: Tab player menu, I inventory, M map, J journey, B crafting, K skills, Y research, L Landsraad, O guild, P social, N Communinet, U customization, E interact, Enter chat (game data: the input mapping context `IMC_General`, read in `docs/admin.md`; not yet confirmed against the client). Rebind in the game's settings if you prefer.

## Keys

| Key | Opens or does |
|---|---|
| Tab | Player menu |
| I | Inventory |
| M | Map |
| J | Journey (story steps, contracts, unclaimed rewards) |
| B | Crafting (personal crafting) |
| K | Skills (and the Specializations tab) |
| Y | Research menu (Intel) |
| L | Landsraad |
| O | Guild |
| P | Social (friends, party, private messages) |
| N | Communinet (message replay, Harvester Radio, event log) |
| U | Customization |
| E | Interact |
| Enter | Chat |
| V (hold) | Proximity voice (community, https://game8.co/games/Dune-Awakening/archives/523562) |
| Middle mouse | Ping (community, same source; "Ping" is a bindable action in game text) |

Keys are from the game data as noted above; V and middle mouse are community reports.

## Features worth knowing

- Radial wheel and hotbar: equip loadout items from the Inventory menu and select them from the radial wheel or hotbar; items auto-fill empty slots (game text).
- Quick Swap: mark one item for Quick Swap on the loadout wheel and double-tap Holster to switch to and from it; the Maula pistol starts assigned (game text).
- Holster: holding a weapon slows you; holster to move faster (game text).
- Waypoints: set one on the map or through binoculars; tracking a journey step shows a directional arrow (game text).
- Map filters and legend: filter for resources (Ores, Crystals, Foliage, Salvageable, Spice Field, Flour Sand) and location types (game text).
- Status Screen: detailed character and world information, including Heat Level against Heat Protection (game text).
- Debuff icons show what is affecting you and for how long (game text).
- Communinet: replay missed radio messages; read the Activity / Event Log to see what destroyed a base or vehicle (game text).
- Drink Catchpockets is its own input, separate from drinking a container (game text).
- Party members get markers on the map, including when they are in a vehicle or on another map (game text).
