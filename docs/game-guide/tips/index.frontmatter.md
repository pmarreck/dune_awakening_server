# Tips and techniques

Short, practical advice, one topic per entry. The topic chapters one level up hold the full mechanics; these entries say what to do with them. Facts carry the same provenance tags as the chapters. `(server config)` means this world's settings files or Funcom's shipped defaults in the server image (build 25789279).

New players should read [first hours](first-hours.frontmatter.md), [common newbie mistakes](common-newbie-mistakes.frontmatter.md) and [what is different on this server](this-server.frontmatter.md) first.
