# Common newbie mistakes

**Quick answer.** The expensive ones are worm deaths (stopping or shielding on open sand), losing vehicles (parking on sand or outside your claim, leaving one behind when you change maps), and dying far from a Respawn Beacon with a full bag.

| Mistake | Prevention | Source |
|---|---|---|
| Lingering on open sand to loot, mine or look around | Cross by the shortest line and stop only on rock; the threat meter does not drain on sand | game text; server config |
| Turning on a personal shield or suspensor in the desert | Shields and suspensors enrage worms; shield threat is 500 per second against 15 for walking | game text; server config |
| Crouching to "sneak" past a worm | Crouching builds threat at the same rate as walking | server config |
| Walking onto drumsand or quicksand | Watch the map hazard markers and scan; drumsand attracts the worm, quicksand can kill | game text |
| Harvesting a spice blow site too early or too late | Do not be near when a blow erupts (the shockwave destroys everything nearby) and leave before the worm arrives | game text |
| No Respawn Beacon | Craft one early and move it with you; only one is active at a time | game text |
| Carrying everything everywhere | Store valuables at base; only carried items drop, and a worm takes them for good | game text |
| Parking outside your claim or on sand | Vehicles outside a claim decay even sheltered; park inside your base under a roof | game text |
| Leaving a ground vehicle behind when changing maps | It is destroyed; store it in the Vehicle Backup Tool first | game text |
| Drinking raw blood as the main water source | It lowers maximum health; purify it at base | game text |
| Running around in the midday sun | Sunstroke speeds dehydration; use shade and travel at night | game text |
| Ignoring unspent skill points and Intel | Spend them; the game reminds you because they do nothing unspent | game text |
| Over-building the first base | The journey moves you north and has you abandon it; keep it small | game text |
| Unpowered machines and base shield | Feed the generator Fuel Cells | game text |
| Sitting in the Escape menu out in the desert | The world does not pause; water keeps draining | verified on this server |
| Selling everything to NPC vendors | They buy back at a small fraction; use the Exchange for valuable items | community, pre-1.5 |
| Spending Imperial Permits on throwaway uniques | Each unique craft uses one permit; more come from found schematics or Intel | game text |
