# Daily and weekly routines

**Quick answer.** Each session: refuel generators, empty refineries and fabricators, refill water, then run a gathering or contract loop. Each day: use your 5 Mnemonic Recollections on Landsraad missions (they bank for up to 7 days). Each week: clear Deep Desert Testing Stations for Intel before the Coriolis storm, and check the Landsraad vendor restock (game text; wiki).

## Every session

1. Base check: generator fuel, circuit status, water in cisterns, finished items waiting in fabricator storage (game text: completed orders go to the fabricator's storage).
2. Queue the next refining and crafting jobs before you leave, so they run while you are away. On this server crafting and refining are instant (`CraftingTimeMultiplier=0`, server config), so this step is simply restocking inputs.
3. Fill water containers; drink to above two thirds (game text).
4. Pick up contracts at the nearest board on the way out (wiki, https://awakening.wiki/Contracts).
5. Dawn is the best time for dew reaping (game text).

## Every day

- Mnemonic Recollections: "You gain 5 Mnemonic Recollections per day" and unused ones accumulate "for up to 7 days"; spending one on a Landsraad mission adds the Recollection Reward (specialization XP, faction standing, House Scrip) (game text; patch notes, Chapter 3). Needs a faction and a faction-aligned guild (game text).
- Respec cost steps back down one level every 6 hours (patch notes 1.3.0.0), so experiment with builds no more than once per session.

## Every week

- Deep Desert Testing Stations hold Intel that refreshes weekly (wiki, https://awakening.wiki/Intel).
- The Landsraad crafting vendor's stock is limited and restocks weekly (game text).
- The Landsraad council passes a new server-wide decree each week (game text); check which bonus is active (for example "CHOAM Refining Contract" cuts refining time and repair cost) and plan around it (game text).
- Coriolis storm: on this server it is warned 6 hours ahead (verified on this server). Empty Deep Desert bases and vehicles before it; afterwards, Hagga Basin resource nodes have moved and need re-surveying (game text; wiki).

## A simple gathering route

- Survey an area once with a probe, then filter the map for the resource you need (Ores, Crystals, Foliage, Salvageable, Flour Sand) (game text).
- Chain nodes along rock, carrying an empty bag and a vehicle with an inventory module; use Cutteray Analysis Mode on every node for more yield (game text).
- Loop through a scavenger camp for Fuel Cells and blood on the way home (game text).
- Node respawn on this server is at default (`ResourceRespawnSpeed=1`) and mining output is tripled (`Dune.GlobalMiningOutputMultiplier=3.0`, vehicle mining also 3.0) (server config).
