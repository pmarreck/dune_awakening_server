2026-10-06: an update's start raced the 5-minute heal timer. The repo's `heal` command honored update.lock, but `systemctl --user cat dune-world-heal.service` showed ExecStart still running `dune-awakening start --no-warn`. Fix was made repo-side (start/restart defer to the lock). Lesson: when behavior contradicts the code, read the installed unit first; also, the daily update check was `--json` without `--notify`, which is why a Steam build went unnoticed for four days.
